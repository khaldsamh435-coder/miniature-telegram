# مِعيار — منصة النحو العربي

موقع تعليمي عربي ثابت وجاهز للنشر على Vercel. لا يحتاج قاعدة بيانات أو مفاتيح API.

## النشر
1. فك ضغط الملف.
2. أنشئ مستودعًا جديدًا على GitHub.
3. ارفع محتويات هذا المجلد إلى جذر المستودع (بحيث يكون `index.html` في الجذر).
4. افتح Vercel وسجّل الدخول بحساب GitHub.
5. اختر Add New → Project، ثم استورد المستودع.
6. Framework Preset: Other. اترك Build Command وOutput Directory فارغين، ثم Deploy.
7. افتح رابط Vercel بعد اكتمال النشر واختبر الموقع.

## الملفات
- `index.html`: الصفحة الرئيسية.
- `assets/style.css`: التصميم المتجاوب.
- `assets/app.js`: الدروس والاختبار التفاعلي.
- `manifest.json`: إعدادات تطبيق الويب.
- `service-worker.js`: تخزين ملفات الواجهة الأساسية.

## ملاحظة عن تثبيت التطبيق
الـ manifest لا يحدد أيقونة حتى الآن. لإكمال التثبيت، أضف صورتين PNG فعلًا بأبعاد 192×192 و512×512 داخل مجلد `icons` ثم أضف مساريهما إلى `manifest.json`.
